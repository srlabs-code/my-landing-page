Privacy Policy

Lantern Vault Publisher · Last updated: October 27, 2026

1. Use of YouTube API Services

Lantern Vault Publisher ("the tool") uses YouTube API Services to publish videos to The Lantern Vault's own YouTube channel. Google's use of information is governed by the Google Privacy Policy, and use of YouTube is governed by the YouTube Terms of Service.

2. Who the Tool Is For

The tool is used only by the owner of The Lantern Vault channel, on their own computer, signed in with their own Google account. It has no other users and is not offered to the public.

3. What the Tool Accesses

With the owner's permission (Google sign-in, scope youtube.force-ssl), the tool:

  • reads the signed-in channel's name, to confirm it is publishing to the right channel;
  • uploads the owner's own videos, with their title, description, tags, category, language and publish time;
  • uploads the thumbnail image and caption file the owner made for each video;
  • lists the channel's own playlists, creates one if needed, and adds the new video to it;
  • reads the new video's privacy status, and posts one comment written by the owner on their own video.

It does not read, collect or store data about viewers or other users, comments by others, analytics, or any account other than the owner's.

4. What Is Stored, and Where

  • The Google sign-in token is stored only on the owner's computer, in a local file, so the owner doesn't have to sign in for every upload. It is never sent anywhere except to Google.
  • The tool keeps a local note of each uploaded video's ID and link, to avoid uploading the same video twice.
  • Nothing is stored on any server run by the tool. There is no database, no analytics and no cookies.

5. Sharing

No information obtained through YouTube API Services is shared with, sold to or disclosed to anyone. The only data sent anywhere is the owner's own video material, sent to YouTube to be published.

6. Revoking Access and Deleting Data

Access can be revoked at any time on the Google security settings page (Third-party apps with account access → Lantern Vault Publisher → Remove access). Deleting the local token file on the owner's computer removes the stored sign-in; the tool keeps no other copy.

7. Changes to This Policy

If this policy changes, the new version will be posted on this page with a new date.
